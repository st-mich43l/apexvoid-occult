# Calibration boundary

This corpus pipeline acquires human evidence.

It does **not** tune Palace Overview coefficients.

`READY_FOR_EXPERT_DATA_COLLECTION` / `PILOT_READY` ≠ `GO_FOR_CALIBRATION`.

`GO_FOR_CALIBRATION` remains a later machine state from Benchmark V2 readiness policy (overlap, usable pairwise, school reliability, holdout, floors).

When that gate is genuinely true, Stage A may tune **quality normalization only**.
