## Version discipline

Once a candidate decision/corpus is published, its scoring semantics must not be changed under the same engine/knowledge/formula version. A semantic change requires a new candidate/version or an explicit lineage-correction PR that invalidates and reruns prior research artifacts.

Historical READMEs/decisions may remain in Git for provenance, but superseded executable duplicate modules should be removed rather than kept as parallel authorities.

Production Annual Axes remains V0.11 until a separately reviewed release PR promotes a later candidate.
