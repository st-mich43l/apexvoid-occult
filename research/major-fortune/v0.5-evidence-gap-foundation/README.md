# Major Fortune V0.5 Evidence Gap Foundation

This directory establishes the authoritative, truthful state of Major Fortune's evidentiary gaps prior to Source Acquisition Round 1.

## Objective
Provide an undisputed inventory, matrix, and backlog of all runtime signals and missing doctrines that require acquisition or adjudication.

## Components
- `inventory/`: The exact runtime and research backlog inventories.
- `matrices/`: Readiness, evidence gap, and school policy matrices mapping every dimension.
- `reports/`: Measurements extracted directly from the corpus evaluator pillars.
- `queue/`: Automated queues representing the workload for Source Acquisition.
- `contradictions/`: Known open contradictions.

## Run
Use `npm run research:major-fortune-v05-gap:all` to run extraction, matrix generation, report building, and determinism checking.
