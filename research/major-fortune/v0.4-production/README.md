# Major Fortune V0.4 Nam Phái Transformation Candidate

This directory contains research, validation, and audit scripts for the V0.4 candidate of the Major Fortune module.

## Goal
Enable Nam Phái Tứ Hóa (Major Fortune Transformations) in the `v0.3-ordinal` calculation engine.
This uses the existing Calculation Core `tuHoaTargets` for the Nam Phái school.

## Feature Flag
`VITE_ZIWEI_MAJOR_FORTUNE_V04_NAM_PHAI_TRANSFORMATIONS=true`

## Tasks
1. Audit score distribution and band migration against the frozen corpus.
2. Ensure temporal independence.
3. Generate reports for the decision to promote to production.
